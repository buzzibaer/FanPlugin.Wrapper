# Fan20320 Design

## Goal

Add a dedicated wrapper implementation for the fan controlled by the decompiled Android app. It must select media already present on the SD card without using the app's upload protocol.

## Public API

`Fan20320` exposes the existing `playVideoWithId(string videoID)` API. The ID keeps the existing wrapper meaning: it identifies a file, rather than a zero-based position in the device's list.

For example, `playVideoWithId("5")` selects `000005.bin`.

## Protocol Behavior

The implementation connects to the Android-app protocol endpoint, defaulting to `192.168.4.1:20320`. It uses the app's persistent command connection, handshake, command frame, and response frame.

On connection it reads and parses the fan's file list. The list contains file names and status data. To select a video, the implementation finds the configured numeric filename for the requested ID, determines its zero-based position in the received list, and sends the select-file command with that position.

The app protocol uses a select-file command made of `B` followed by one raw byte. That byte is the zero-based position, not the media ID.

## File Naming Contract

The SD card must use zero-padded numeric file names such as `000001.bin` and `000005.bin`. This existing documented ordering convention lets the wrapper map an API ID to the device's file-list entry without treating the ID as a fragile list offset.

## Error Handling

The wrapper returns a clear error when it cannot connect, cannot parse the device's file list, receives an out-of-range list position, or cannot find the requested numeric file name. It must not send a selection command when the lookup fails.

## PupScript

`FAN_HARDWARE_VERSION = 20320` selects `FanPlugin.Wrapper.Fan20320`. Existing calls such as `fan.playVideoWithId(5)` remain unchanged. Endpoint and timeout overrides follow the existing wrapper conventions.

## Exclusions

No media conversion, upload, deletion, or SD-card write support is included. The Android upload connection and its distinct handshake are out of scope.
